Rating-site logos (IMDb, Rotten Tomatoes, Metacritic, TMDB), taken from the Simple Icons set (CC0) and tinted in each site's colour.
The names and logos belong to their owners; they are used here only to show which site a score comes from.
To use your own artwork, replace the .svg files in this folder (keep the file names: imdb, rotten_tomatoes, metacritic, tmdb).
